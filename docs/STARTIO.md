# إعداد Start.io
1. أنشئ تطبيقًا في portal.start.io بالحزمة `discussion.com.paper` وانسخ App ID.
2. محليًا/CI: ضع `STARTIO_APP_ID` في gradle.properties (أو Secret بنفس الاسم). فارغ = الإعلانات معطلة.
3. ثبّت إصدار SDK الصحيح في `STARTIO_SDK_VERSION` (القيمة الحالية `5.+` لم أتحقق منها دون إنترنت) وراجع أسماء الفئات في `Platform.kt`.
4. نسخ debug تستخدم وضع الاختبار. الإعلان البيني يظهر كل 3 جولات كحد أدنى بعد نتيجة الجولة، والبانر في شريط سفلي منفصل.
