# مداقشة (Discussion) — discussion.com.paper
لعبة ورق عربية لأندرويد (Kotlin + Compose). تعمل دون إنترنت، مع Firebase اختياري وإعلانات Start.io.

- القواعد: `docs/RULES.md` • التوقيع: `docs/SIGNING.md` • Firebase: `docs/FIREBASE.md` • Start.io: `docs/STARTIO.md`
- الاختبارات: `gradle :core:test` • البناء: GitHub Actions (`.github/workflows/build.yml`) ثم نزّل الـ APK من Artifacts.
- **الحالة:** الكود لم يُبنَ ولم يُختبر بعد (لا يوجد SDK أو إنترنت في بيئة الكتابة). شغّل Actions لأول مرة وأرسل لي أي أخطاء.
